# ⚖️ ผู้ช่วยกฎหมายสำหรับคนทำงาน (Labor & PDPA RAG Chatbot)

แชตบอตตอบคำถามเรื่อง **สิทธิลูกจ้าง** และ **ข้อมูลส่วนบุคคล** จากตัวบท
พระราชบัญญัติคุ้มครองแรงงาน พ.ศ. 2541 (ฉบับรวมแก้ไขถึงฉบับที่ 9 พ.ศ. 2568) และ
พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) ด้วยเทคนิค RAG (Retrieval-Augmented Generation)
ทุกคำตอบอ้างเลขมาตรา แสดงตัวบทที่ใช้ตอบ และตอบว่า "ไม่พบข้อมูลในเอกสารที่มีอยู่" เมื่อเอกสารไม่มีคำตอบ

🔗 **เว็บแอป:** _(เพิ่มหลัง deploy)_

---

## แนวคิดของ Domain

คนทำงานส่วนใหญ่มีคำถามกฎหมายใกล้ตัวสองเรื่อง

1. **สิทธิลูกจ้าง** เช่น ถูกเลิกจ้างได้ค่าชดเชยเท่าไร ลาป่วย/ลาคลอดได้กี่วัน ค่าล่วงเวลากี่เท่า
2. **ข้อมูลส่วนบุคคลในที่ทำงาน** เช่น บริษัทเก็บข้อมูลพนักงานต้องขอความยินยอมไหม ข้อมูลรั่วไหลต้องแจ้งภายในกี่ชั่วโมง

คำตอบที่หาได้ทั่วไปมักเป็นบทความที่อาจล้าสมัย (เช่น สิทธิลาคลอดเพิ่มจาก 98 เป็น 120 วันตามฉบับที่ 9 พ.ศ. 2568)
ระบบนี้จึงตอบจาก **ตัวบทฉบับรวมแก้ไขล่าสุด** เท่านั้น และอ้างอิงเป็นมาตราที่ผู้ใช้ตรวจสอบต่อได้

## วิธีใช้งาน

### บนเว็บ
1. เลือกกฎหมายที่ต้องการค้นที่แถบด้านซ้าย (ค่าเริ่มต้นค้นทั้งสองฉบับ) และปรับจำนวนมาตราที่ค้นได้ 2–8 มาตรา
2. พิมพ์คำถามภาษาไทยหรืออังกฤษ หรือกดปุ่มคำถามตัวอย่าง
3. เปิด **"แหล่งอ้างอิง"** ใต้คำตอบเพื่อดูตัวบทเต็มของมาตราที่ใช้ตอบ และ **"คำค้นที่ระบบใช้"** เพื่อดูคำค้นหลังเรียบเรียงใหม่
4. ถามต่อเนื่องได้ เช่น "แล้วถ้าทำงาน 10 ปีล่ะ" — กด "เริ่มแชตใหม่" เพื่อล้างประวัติ

### รันบนเครื่อง
```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # แล้วใส่ GROQ_API_KEY ของตัวเอง
streamlit run app.py
```

### Deploy บน Streamlit Community Cloud
1. share.streamlit.io → Create app → เลือก repo นี้, branch `main`, ไฟล์ `app.py`
2. Advanced settings → Python 3.11 และใส่ Secrets: `GROQ_API_KEY = "..."`
3. API key เก็บใน Secrets ของ Streamlit เท่านั้น — `.streamlit/secrets.toml` อยู่ใน `.gitignore`

## สถาปัตยกรรม RAG

```
คำถาม ──► (คำถามต่อเนื่อง / ไม่ใช่ภาษาไทย?) ──► Query rewriting ด้วย LLM → คำค้นภาษาไทย
                                   │
                                   ▼
             Query expansion (อภิธานศัพท์ภาษาชาวบ้าน → ศัพท์ตัวบท)
                    │                                   │
                    ▼                                   ▼
         FAISS (multilingual-e5-small)          BM25 (pythainlp newmm)
                    └──────────► RRF (k=60) ◄───────────┘
                                   │  มาตราละ 1 ผลลัพธ์, top-k
                                   ▼
                  cosine สูงสุด < 0.81 ? ──ใช่──► "ไม่พบข้อมูลในเอกสารที่มีอยู่" (ไม่เรียก LLM)
                                   │ไม่
                                   ▼
          System prompt + ตัวบทเต็มของแต่ละมาตรา [1]..[k] + ประวัติแชต 3 รอบ
                                   │
                                   ▼
                    Groq openai/gpt-oss-120b (temperature 0.1)
                                   │
                                   ▼
            คำตอบ + อ้างอิง [n] + แหล่งอ้างอิงที่แสดงใน UI ทุกครั้ง
```

| เทคนิค | การนำไปใช้ | เหตุผล |
|---|---|---|
| **Document Loading & Chunking** | ดึงข้อความจาก PDF ด้วย PyMuPDF → `scripts/split_law.py` ลบหัว/ท้ายกระดาษ แก้สระอำที่แตก ต่อบรรทัดที่ถูกตัด แปลงเลขไทยเป็นอารบิก แล้วแยกไฟล์ละหมวด → `rag/loader.py` ตัด **1 chunk = 1 มาตรา** (มาตรายาวเกิน 800 ตัวอักษรแบ่งย่อย overlap 100 โดยเริ่มที่ขอบคำ) | มาตราคือหน่วยที่อ้างอิงได้ในทางกฎหมาย การตัดตามความยาวคงที่จะตัดกลางมาตราและอ้างอิงไม่ได้ |
| **Embedding & Vector Search** | `intfloat/multilingual-e5-small` (prefix `query:`/`passage:`, normalize) + FAISS `IndexFlatIP` | โมเดลเล็ก (~470 MB) พอสำหรับหน่วยความจำของ Streamlit Cloud และรองรับไทย/อังกฤษ; คลังมีไม่กี่ร้อย chunk จึงใช้ index แบบค้นทั้งหมดได้ |
| **Hybrid Retrieval** | BM25 บนคำที่ตัดด้วย pythainlp + รวมอันดับด้วย Reciprocal Rank Fusion; คืนผลมาตราละหนึ่งรายการ และส่ง **ตัวบทเต็มของมาตรา** ให้ LLM | BM25 จับเลขมาตราและศัพท์เฉพาะได้ตรงตัว; การส่งมาตราเต็มกันกรณีคำตอบอยู่ในส่วนอื่นของมาตรายาว (เช่น ม.118 อนุมาตรา 5) |
| **Query rewriting / expansion** | คำถามต่อเนื่องหรือคำถามที่ไม่ใช่ภาษาไทย → LLM เรียบเรียงเป็นคำค้นภาษาไทยที่สมบูรณ์; อภิธานศัพท์เล็ก ๆ เติมศัพท์ตัวบทเมื่อพบคำชาวบ้าน (เช่น "รั่วไหล" → "การละเมิดข้อมูลส่วนบุคคล") | ตัวบทเป็นภาษาไทยและใช้ศัพท์กฎหมาย คำค้นภาษาอังกฤษหรือภาษาพูดค้นไม่เจอ |
| **Prompt Engineering** | System prompt บังคับตอบจาก `<context>` เท่านั้น, อ้าง `[n]` + ชื่อ พ.ร.บ. + มาตรา, ปฏิเสธด้วยประโยคตายตัว, แยกมาตราที่ใช้เฉพาะบางกรณีเป็นข้อสังเกต | ดูข้อความเต็มด้านล่าง |
| **การปฏิเสธ 2 ชั้น** | (1) threshold cosine **0.81** ปฏิเสธโดยไม่เรียก LLM (2) กฎใน prompt สำหรับคำถามนอกเรื่อง/ไม่มีคำตอบ; ถ้าปฏิเสธจะไม่แสดงแหล่งอ้างอิง | ค่า threshold ได้จาก `evaluate.py` (cosine ต่ำสุดของคำถามที่มีคำตอบ 0.828 ลบ 0.02) |
| **Large Language Model** | Groq `openai/gpt-oss-120b`, temperature 0.1, `reasoning_effort="low"` | ตอบภาษาไทยจากตัวบทได้ถูกต้องที่สุดในโมเดลที่ Groq มีให้ (llama-3.3-70b ถูกถอดแล้ว) |
| **Chatbot Interface** | Streamlit `st.chat_message`/`st.chat_input`, ประวัติใน `session_state`, แหล่งอ้างอิงใน expander ทุกคำตอบ, ตัวกรองกฎหมาย, ปุ่มคำถามตัวอย่าง; ธีม Legal (น้ำเงินเข้ม/ทอง, ฟอนต์ IBM Plex Sans Thai) ออกแบบด้วย ui-ux-pro-max | โหลดโมเดลและ index ครั้งเดียวด้วย `@st.cache_resource` |

### System prompt ที่ใช้ (`rag/prompt.py`)
```
คุณคือ "ผู้ช่วยกฎหมายสำหรับคนทำงาน" ... โดยใช้ตัวบทใน <context> ที่ให้มาเท่านั้น
0. ถ้าคำถามไม่เกี่ยวกับการจ้างงาน สิทธิลูกจ้าง หรือข้อมูลส่วนบุคคล ให้ตอบเพียง "ไม่พบข้อมูลในเอกสารที่มีอยู่" ทันที
1. ใช้เฉพาะข้อมูลใน <context> ห้ามใช้ความรู้ภายนอก ห้ามเดา ห้ามแต่งตัวเลข อัตรา หรือเลขมาตรา
   ใช้เฉพาะมาตรา/อนุมาตราที่เงื่อนไขตรงกับคำถาม; มาตราที่ใช้เฉพาะบางกรณีให้แยกเป็นข้อสังเกต
2. ทุกประโยคที่อ้างกฎหมาย ต้องใส่ [n] และระบุชื่อ พ.ร.บ. กับเลขมาตรา
3. ถ้า <context> ไม่มีคำตอบ ให้ตอบ "ไม่พบข้อมูลในเอกสารที่มีอยู่" ประโยคเดียว
4. ตอบภาษาเดียวกับคำถาม ใช้ภาษาง่าย และเขียนจำนวนเป็นตัวเลขกำกับ
5. ปิดท้ายว่าเป็นข้อมูลเบื้องต้น ไม่ใช่คำปรึกษาทางกฎหมาย
```

## แหล่งที่มาของเอกสาร (`data/` — 27 ไฟล์, 379 chunk)

| ไฟล์ | เนื้อหา | ต้นทาง |
|---|---|---|
| `labor_ch00.txt` – `labor_ch16.txt`, `labor_ch99.txt` (18 ไฟล์) | พ.ร.บ.คุ้มครองแรงงาน พ.ศ. 2541 ฉบับปรับปรุงล่าสุด (รวมแก้ไขถึงฉบับที่ 9 พ.ศ. 2568) แยกตามหมวด 1–16 และบทเฉพาะกาล | กองนิติการ กรมสวัสดิการและคุ้มครองแรงงาน (ฉบับพิมพ์ของสำนักงานคณะกรรมการกฤษฎีกา): https://legal.labour.go.th/images/law/Protection2541/2568_protectionpdf.pdf |
| `pdpa_ch00.txt` – `pdpa_ch07.txt`, `pdpa_ch99.txt` (9 ไฟล์) | พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 แยกตามหมวด 1–7 และบทเฉพาะกาล | สำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส.): https://www.pdpc.or.th/wp-content/uploads/2023/12/1_Personal-Data-Protection-2562.pdf |

ทุกไฟล์ขึ้นต้นด้วยหัว `LAW:` / `CHAPTER:` / `SOURCE:` ซึ่งระบบใช้เป็น metadata ของแหล่งอ้างอิง

สร้างคลังซ้ำได้ด้วย:
```bash
curl -L -o scripts/raw/labor.pdf "https://legal.labour.go.th/images/law/Protection2541/2568_protectionpdf.pdf"
curl -L -o scripts/raw/pdpa.pdf  "https://www.pdpc.or.th/wp-content/uploads/2023/12/1_Personal-Data-Protection-2562.pdf"
pip install -r requirements-dev.txt
python -c "import pymupdf; [open(f'scripts/raw/{n}.txt','w').write(''.join(p.get_text() for p in pymupdf.open(f'scripts/raw/{n}.pdf'))) for n in ['labor','pdpa']]"
python scripts/split_law.py scripts/raw/labor.txt --law labor --name "พระราชบัญญัติคุ้มครองแรงงาน พ.ศ. 2541" --source "<URL>"
python scripts/split_law.py scripts/raw/pdpa.txt --law pdpa --name "พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562" --source "<URL>"
```

## ตัวอย่าง Prompt ที่ใช้สั่ง AI ระหว่างพัฒนา

พัฒนาร่วมกับ Claude Code (Claude Opus 5.5) ตามขั้นตอน brainstorm → spec → plan → TDD
(spec และแผนอยู่ใน `docs/superpowers/`)

1. **เริ่มโปรเจกต์:** `/superpowers:brainstorming ให้สร้าง Web Application ระบบ RAG ... (วางโจทย์ทั้งหมด)`
2. **เลือกหัวข้อ:** `ผู้ช่วยกฎหมายสำหรับประชาชน --> ตอบคำถามเรื่อง PDPA หรือกฎหมายแรงงานจากตัวบทกฎหมาย` → `C ทั้งสองฉบับ`
3. **แหล่งข้อมูล:** `A ดึงจากแหล่งทางการ`
4. **แนวทางเทคนิค:** `แนวทาง 1` (chunk ตามมาตรา + hybrid FAISS/BM25 + threshold) และ `เก็บ query rewriting ไว้`
5. **อนุมัติขั้นตอน:** `โอเค เขียน spec ได้เลย` → `โอเค เขียน implementation plan ได้เลย` → `โอเค ใช้ Native ลงมือได้เลย`
6. **ออกแบบหน้าเว็บ:** `ถ้าออกแบบเว็บ UI ให้ใช้ ui-ux-pro-max`
7. **ความถูกต้อง:** `ถ้าถามนอกเรื่องต้องตอบไม่ได้`

ปัญหาที่พบและแก้ระหว่างพัฒนา (บันทึกใน git history):
- PDF ราชกิจจาฯ ดึงข้อความแล้วสระอำแตก ("ส านัก") และ pypdf ทำวรรณยุกต์หาย → ใช้ PyMuPDF + กฎแก้ข้อความ
- คำถาม "ทำงาน 10 ปี" ตอบผิดเพราะอนุมาตราที่ถูกอยู่ใน chunk ที่ค้นไม่เจอ → ส่งตัวบทเต็มของมาตราให้ LLM
- คำถามภาษาอังกฤษค้นไม่เจอ (embedding ข้ามภาษาอ่อน) → แปลเป็นคำค้นภาษาไทยก่อนค้น

## ข้อจำกัด

- ครอบคลุมเฉพาะตัวบท พ.ร.บ. สองฉบับ ไม่รวมกฎกระทรวง ประกาศ (เช่น อัตราค่าจ้างขั้นต่ำ) หรือคำพิพากษา
- Groq แบบฟรีจำกัด 8,000 token/นาที หากมีผู้ใช้พร้อมกันหลายคน ระบบจะรอแล้วลองใหม่หรือแจ้งให้ลองอีกครั้ง
- เป็นข้อมูลเบื้องต้น ไม่ใช่คำปรึกษาทางกฎหมาย — ควรตรวจตัวบทในแหล่งอ้างอิงทุกครั้ง
